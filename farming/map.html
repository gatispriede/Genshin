The map

All 946 Saurian spawns from the official map, drawn on the real terrain. Fat clusters are circled; the orange arrows join the six best into one run. Click a circle once you’ve cleared it.

Saurian spawn map

  • On the route — numbered in order
  • Other cluster — number is the Saurian count
  • Cleared today
  • A single spawn
  • Teleport waypoint — blue diamond, gold circle for a Statue

Drag to pan, scroll to zoom. Place names come from the game’s own map data, so once you find a circle you can read where it is and teleport there. Cleared circles reset themselves each day, like the spawns do.

Want this for something else? The same generator draws any category the official map tracks — world quests, oculi, chests, a particular enemy — onto the same terrain, in one command. node tools/build-map-data.mjs --labels lists what’s available; tools/README.md has the rest.
