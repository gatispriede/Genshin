World quests

The same map, pointed at something else entirely — 576 world quest starts across all of Teyvat. Built with one command, from the same generator that drew the Saurians.

  • Clustered — numbered in order

  • Teleport waypoint — blue diamond, gold circle for a Statue

This one spans the whole continent, so it is built at the coarsest tile level (--level 3) — 90 tiles instead of the 1287 a full-resolution Teyvat map would pull. Place names appear as you zoom in, or 292 of them would land on top of each other.

Reputation quests are not on here, and cannot be. Checked against all 793 categories the official map carries: there is no Reputation, Bounty, Request or Commission type. Reputation Bounties and Requests rotate weekly from a per-region pool, so they have no fixed coordinates to pin — no map has them, this one included. World quests are the nearest fixed thing.

Per-region datasets that do exist, if that was the shape you wanted: Shrines of Depths, Mora chests and the offering trees each have their own label per region. node tools/build-map-data.mjs --labels lists them.
