## How to refresh this

Needs their logged-in Chrome. Deep links to SPA routes render blank.

1. `https://www.hoyolab.com/accountCenter/postList?id=498210497`
2. Scroll to the **Genshin Impact** card, click it — opens the Chronicle with
   the right user id attached
3. Summary page gives AR, achievements, oculi, chests, waypoints
4. Exploration — grab the container holding several region names:
   ```js
   const names = ['Mondstadt','Liyue','Inazuma','Sumeru','Fontaine','Natlan'];
   [...document.querySelectorAll('div')]
     .filter(d => names.filter(n => (d.innerText||'').includes(n)).length >= 4)
     .pop().innerText;
   ```
5. Per-character gear — click each portrait in the **My Characters** carousel,
   then:
   ```js
   const all = [...document.querySelectorAll('div')];
   const c = all.filter(d => d.innerText?.includes('Character Stats')
                          && d.innerText.includes('Artifacts'));
   c[c.length - 1].innerText.replace(/\n{2,}/g,'\n');
   ```
   Carousel sits around y≈207 once scrolled; the arrow at the right pages it.

Intercepting `fetch` for `character/detail` also works but the hook dies on any
navigation, and the tool blocks returning request headers.
