Nothing can look up which codes you have redeemed. No API exposes an account's redemption history, and HoYoLAB does not publish it. The only way to find out is to enter a code and see whether the game says already in use — which is harmless. So the ticks here are your own record, kept in this browser, not something read from your account.
Why the dead list is kept. This project has already been burned once: an aggregator reported roughly 660 Primogems of codes, about half of which were dead — including three 100-Primogem 7.2 livestream codes that had expired five days earlier. Livestream codes live about 24–48 hours. The correction is recorded, and the fix was to cross-check two sources against a timestamped tracker, which is what the date above means.
